# Pixelator

이미지, GIF, 영상을 선택한 픽셀 해상도와 팔레트로 변환하는 브라우저 기반 도구입니다. 외부 서버나 라이브러리를 사용하지 않으며, 최종 배포물은 `index.html` 한 파일입니다.

## 실행

`index.html`을 최신 브라우저에서 열면 됩니다. 파일은 브라우저 메모리 안에서만 처리되며 업로드되지 않습니다.

## 빌드

Node.js가 설치된 환경에서 다음 명령을 실행합니다.

```powershell
node build.js
```

`build.js`는 `src/template.html`, `src/styles.css`, 아래 JavaScript 모듈을 정해진 순서로 결합해 `index.html`을 만듭니다. 기존 `index.html`이 있으면 프로젝트 규칙에 따라 먼저 `index_BU.html`로 덮어써 백업합니다.

빌드와 핵심 색상 처리의 스모크 테스트는 다음 명령으로 실행합니다.

```powershell
node tests/smoke.js
```

## 모듈 구성

| 파일 | 역할 |
| --- | --- |
| `src/template.html` | 화면 구조와 접근성 마크업 |
| `src/styles.css` | 반응형 UI와 픽셀 미리보기 스타일 |
| `src/state.js` | 기본 설정과 상태 변경 이벤트 |
| `src/palettes.js` | 기본/사용자 팔레트 파싱 |
| `src/color-space.js` | sRGB와 지각 기반 OKLab 색 공간 변환 |
| `src/outline.js` | 투명도 판정과 픽셀 단위 외곽선 확장·합성 |
| `src/pixelate.js` | 색상 양자화와 Ordered/Floyd–Steinberg 디더링 |
| `src/adaptive-palette.js` | 원본 색상 분포 기반 8·16·32색 팔레트 추출 |
| `src/gif-decoder.js` | GIF 블록·LZW 해석, 프레임 합성·재생·시간 기반 탐색 |
| `src/media.js` | 이미지, GIF, 영상 로드와 재생 제어 |
| `src/renderer.js` | 원본 비교 미리보기, 저해상도 샘플링과 최근접 확대 렌더링 |
| `src/webm-muxer.js` | VP8·VP9 인코딩 프레임을 WebM/Matroska 구조로 결합 |
| `src/webcodecs-encoder.js` | GIF 빠른 내보내기에 사용하는 WebCodecs 프레임 인코더 |
| `src/exporter.js` | PNG 스냅샷과 무음 WebM 녹화 |
| `src/fast-gif-exporter.js` | WebCodecs 기반 비실시간 GIF 프레임 인코딩 |
| `src/ui.js` | DOM 이벤트, 드래그 분할 비교, 타임라인, 설정 동기화와 드래그 앤 드롭 |
| `src/app.js` | 모듈 초기화 진입점 |

모듈은 빌드 후에도 즉시 실행 함수 단위로 격리되며 `window.Pixelator` 네임스페이스를 통해 필요한 API만 공유합니다. 외부 CDN 의존성이 없어 장기 보관과 오프라인 배포가 가능합니다.

## 처리 방식

1. 원본 프레임을 지정한 가로 픽셀 수로 축소합니다.
2. 팔레트가 선택되면 가장 가까운 색상으로 양자화합니다.
3. 선택한 디더링을 적용합니다.
4. 결과를 최근접 보간으로 정수 배 확대합니다.
5. 투명 미디어라면 확대가 끝난 결과에 선택한 실제 픽셀 두께로 외곽선을 합성합니다.

제한 팔레트는 축소 프레임의 국소 대비를 보강한 뒤 OKLab 거리로 색상을 매칭합니다. `Adaptive` 팔레트는 첫 프레임에서 대표색을 추출해 고정하므로 이미지의 색을 더 잘 보존하면서 GIF·영상의 프레임별 색상 깜빡임을 방지합니다. `자동` 디더링은 16색 이하에서 애니메이션에도 안정적인 Ordered 패턴을 사용합니다.

GIF와 영상은 같은 파이프라인을 프레임마다 실행합니다. GIF는 내장 LZW 디코더로 각 프레임을 합성하고 파일에 기록된 지연 시간에 맞춰 재생하며, 누적 프레임 시간을 사용해 진행도 표시와 임의 프레임 이동을 지원합니다. 진행 바를 조작하면 GIF와 영상 모두 자동으로 일시 정지해 선택한 프레임을 유지합니다. GIF 내보내기는 WebCodecs가 있으면 원본 시간값을 붙여 프레임을 최대 속도로 인코딩하고, 지원되지 않으면 기존 실시간 녹화로 전환합니다. 영상은 처음부터 재생 종료까지 실시간으로 녹화합니다. 내보내기 중 창이 비활성화되면 처리와 녹화를 멈추고 포커스가 돌아오면 재개합니다. 결과 데이터는 브라우저 메모리에 쌓이며 애니메이션 출력은 무음 WebM으로 제공합니다.

## 유지보수 원칙

- 생성된 `index.html`을 직접 수정하지 않고 `src/` 모듈을 수정한 뒤 다시 빌드합니다.
- 기존 소스 파일을 수정할 때는 먼저 같은 위치에 `파일명_BU.확장자` 백업을 생성합니다.
- 팔레트 추가는 `src/palettes.js`와 `src/template.html`의 선택 항목만 함께 수정합니다.
- 픽셀 처리 알고리즘은 UI 코드와 분리해 두어 향후 Web Worker로 옮길 수 있습니다.
- 비정상적으로 긴 원본은 브라우저 메모리 보호를 위해 논리 캔버스 2,048px, 출력 캔버스 4,096px 안에서 원본 비율을 유지하며 자동 축소됩니다.
